# Trivia Game

A trivia quiz game built with React and Redux as part of the Trybe Full Stack Web Development program. Players answer multiple-choice questions fetched from the [Open Trivia Database API](https://opentdb.com/), with a timer, score tracking, and a leaderboard.

## Tech Stack

React · Redux · React Router · CSS

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/AugustoMagalhaes/redux-17-trivia-game.git

# Navigate into the project folder
cd redux-17-trivia-game

# Install dependencies
npm install

# Start the development server
npm start
```

The app will be available at `http://localhost:3000`.

## Running Tests

```bash
npm test
```
